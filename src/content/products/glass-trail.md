Made for project grids. Move over a thumbnail and the picture breaks into ribbed glass strips that refract and shift, then settle back as the trail fades.

## Details

- Set the number of strips, refraction, line strength, colour fringe and trail length
- Slight zoom on hover
- Works on images and video

## What's included

- Framer component
- JavaScript version for any website, with no dependencies
- Example page and a playground
